# Laytime-Demurrage-Calculator-Tanker-Voyage-Charter-
Built an Excel tool that calculates laytime used and demurrage/despatch from a Statement of Facts, applying Asbatankvoy-style terms. Modelled five scenarios: exclusions, half-rate demurrage, invalid NOR, pumping warranty deduction and non-reversible laytime. Verified results against an independent calculation; all data fictional
